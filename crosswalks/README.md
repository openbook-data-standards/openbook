# Crosswalks

Maps from a public taxonomy onto existing OpenBook ids, or onto the
unknown catch-all with a reason (roadmap; sitting leftover). Not a wire
change. OpenBook ids are not invented here.

Cite the public list. CI checks that every OpenBook target exists in
`vocabularies/`.

| File | Public list |
| --- | --- |
| [`betfair-markets.md`](betfair-markets.md) | Betfair Exchange `marketType` strings |
| [`betfair-segments.md`](betfair-segments.md) | Common Betfair soccer period labels |

Source cited: Betfair Exchange Stream API documentation, already linked
from [`../docs/protocol-comparison.md`](../docs/protocol-comparison.md).
