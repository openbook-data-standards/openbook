for the fixture. OpenBook does not mint player, team, or league ids.

| File | What |

a feed MAY also name one community register per sport when one exists
(football: Reep, as cited in `docs/protocol-comparison.md`). Year 2 may
spin this directory into a separate repository (roadmap).
