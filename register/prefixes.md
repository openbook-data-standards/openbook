# Namespace prefixes

Scheme prefixes for `identifier` `propertyID` (Q171). First-come, never
reused. To retire a prefix, mark it retired here and name the redirect.
Do not reassign it.

Kind is publisher, provider, or exchange. This file is the register in
this repository. It is not an entity database of players, teams, or
leagues.
